📌 Step 1: Open Excel and Set Up the Sheet

Open Microsoft Excel on your computer or go to sheets.google.com for the free online version.

📋 Basic Sheet Setup:

1. Open a new blank workbook

2. Name your sheet at the bottom:
Right click on "Sheet1" → Rename → Type "April 2026 Budget"

3. In Cell A1 type:
"MY MONTHLY BUDGET – APRIL 2026"

4. Make it bold and increase font size to 16

5. Leave Row 2 blank for spacing

📌 Step 2: Create the Income Section

Start from Row 3 and create your income section.

💰 Income Section Layout:

Cell What to Type
A3 INCOME
A4 Main Salary
A5 Side Income
A6 Other Income
A7 TOTAL INCOME
B3 AMOUNT (₹)
B4 to B6 Type your actual amounts here
B7 =SUM(B4:B6)

✅ Example: B4 = 15000 (Salary) B5 = 2000 (Side Income) B7 will automatically show = ₹17,000

📌 Step 3: Create the Expense Section

Start from Row 9 (leave Row 8 blank for spacing) and create your expense section.

💸 Expense Section Layout:

Cell Category Budgeted (₹) Actual (₹)
A9 EXPENSES BUDGETED ACTUAL
A10 Rent B10 C10
A11 Groceries B11 C11
A12 Electricity + Gas B12 C12
A13 Mobile + Internet B13 C13
A14 School Fees B14 C14
A15 Petrol + Travel B15 C15
A16 Eating Out B16 C16
A17 Entertainment B17 C17
A18 Medicine + Emergency B18 C18
A19 Savings B19 C19
A20 TOTAL EXPENSES =SUM(B10:B19) =SUM(C10:C19)

📌 Step 4: Add Formulas for Automatic Calculation

This is where Excel becomes really powerful! Add these formulas and everything will calculate automatically.

🔢 Most Important Excel Budget Formulas

Total Income:
Cell B7 → =SUM(B4:B6)
Adds up all income sources automatically
Total Budgeted Expenses:
Cell B20 → =SUM(B10:B19)
Adds up all planned expenses
Total Actual Expenses:
Cell C20 → =SUM(C10:C19)
Adds up all real expenses you spent
Difference (Over or Under):
Cell D10 → =B10-C10
Positive = under budget ✅
Negative = over budget ❌
Remaining Balance:
Cell B22 → =B7-C20
Total Income minus Total Actual Expenses
This shows how much money you have left!

📌 Step 5: Create the Summary Section

Add a summary section below your expenses so you can see the complete picture at a glance!

📊 Summary Section (starting Row 22):

Cell Label Formula
A22 Total Income =B7
A23 Total Expenses (Actual) =C20
A24 Money Remaining =B7-C20
A25 Savings This Month =C19
A26 Savings % =C19/B7*100

📌 Step 6: Add Colours and Formatting

Make your budget easy to read with colours and formatting!

🟢 Green colour for Income rows
Select the row → Home → Fill Color → Green

🔴 Red/Orange colour for Expense rows
Select the rows → Fill Color → Light Red

🔵 Blue colour for Total rows
Bold + Blue background for total rows

📊 Add a Pie Chart
Select expense categories → Insert → Chart → Pie Chart → See exactly where money is going visually!

🔀 Conditional Formatting
Select Difference column D → Home → Conditional Formatting → Green if positive (under budget) → Red if negative (over budget)!

📌 Step 7: Track Every Month

Your Excel budget is now ready! Here is how to use it every month:

📅 Monthly Routine:

1st of every month:
— Copy the sheet for new month
— Update income amounts
— Set budgeted amounts for each category

Every day:
— Add actual expenses in Column C
— Takes just 2 minutes!

End of month:
— Review the summary section
— Compare budgeted vs actual
— Plan improvements for next month

Pro Tip: Create a new sheet tab for every month so you can compare January vs February vs March!

🔢 Key Excel Formulas for Monthly Budget

Formula What it Does Example
=SUM(B4:B6) Adds a range of cells Total income
=B7-C20 Subtracts two cells Remaining money
=B10-C10 Budget vs Actual difference Over or under budget
=C19/B7*100 Calculates percentage Savings percentage
=AVERAGE(B4:B6) Average of values Average monthly expense
=MAX(C10:C19) Finds highest value Biggest expense category
