📌 Step 1: Excel खोलो और Sheet Setup करो

अपने computer में Microsoft Excel खोलो या free online version के लिए sheets.google.com पर जाओ।

📋 Basic Sheet Setup:

1. एक नया blank workbook खोलो

2. नीचे sheet का नाम रखो:
"Sheet1" पर right click करो → Rename → Type करो "April 2026 Budget"

3. Cell A1 में type करो:
"मेरा Monthly Budget – April 2026"

4. उसे bold करो और font size 16 करो

5. Row 2 खाली छोड़ो spacing के लिए

📌 Step 2: Income Section बनाओ

Row 3 से शुरू करो और अपना income section बनाओ।

💰 Income Section Layout:

Cell क्या Type करो
A3 आमदनी (INCOME)
A4 मुख्य तनख्वाह
A5 अतिरिक्त आमदनी
A6 कोई और आमदनी
A7 कुल आमदनी
B3 राशि (₹)
B4 से B6 यहाँ अपनी असली राशि डालो
B7 =SUM(B4:B6)

✅ उदाहरण: B4 = 15000 (तनख्वाह) B5 = 2000 (Side Income) B7 अपने आप दिखाएगा = ₹17,000

📌 Step 3: खर्चे का Section बनाओ

Row 9 से शुरू करो (Row 8 spacing के लिए खाली छोड़ो) और अपना खर्चा section बनाओ।

💸 खर्चा Section Layout:

Cell श्रेणी नियोजित (₹) असली (₹)
A9 खर्चे नियोजित असली
A10 किराया B10 C10
A11 राशन B11 C11

A13 मोबाइल + इंटरनेट B13 C13

A19 बचत B19 C19
A20 कुल खर्चा =SUM(B10:B19) =SUM(C10:C19)

📌 Step 4: Automatic Calculation के लिए Formulas Add करो

यहाँ Excel सच में बहुत powerful हो जाता है! यह formulas add करो और सब अपने आप calculate होगा।

🔢 सबसे ज़रूरी Excel Budget Formulas

कुल आमदनी:
Cell B7 → =SUM(B4:B6)
सभी income sources अपने आप जुड़ जाते हैं
कुल नियोजित खर्चे:
Cell B20 → =SUM(B10:B19)
सभी planned खर्चे जुड़ जाते हैं
कुल असली खर्चे:
Cell C20 → =SUM(C10:C19)
सभी असली खर्चे जो आपने किए
अंतर (ज़्यादा या कम):
Cell D10 → =B10-C10
Positive = budget में रहे ✅
Negative = budget से बाहर गए ❌
बचा हुआ पैसा:
Cell B22 → =B7-C20
कुल आमदनी में से कुल असली खर्चे घटाओ
यह दिखाता है कितना पैसा बचा है!

📌 Step 5: Summary Section बनाओ

खर्चों के नीचे एक summary section add करो ताकि आप एक नज़र में पूरी तस्वीर देख सको!

📊 Summary Section (Row 22 से शुरू):

Cell Label Formula
A22 कुल आमदनी =B7
A23 कुल खर्चे (असली) =C20
A24 बचा हुआ पैसा =B7-C20
A25 इस महीने की बचत =C19
A26 बचत का प्रतिशत =C19/B7*100

📌 Step 6: रंग और Formatting Add करो

अपना budget आसानी से पढ़ने लायक बनाओ रंगों और formatting के साथ!

🟢 हरा रंग Income rows के लिए
Row select करो → Home → Fill Color → Green

🔴 लाल रंग Expense rows के लिए
Rows select करो → Fill Color → Light Red

🔵 नीला रंग Total rows के लिए
Bold + Blue background Total rows के लिए

📊 Pie Chart Add करो
खर्चों की categories select करो → Insert → Chart → Pie Chart → देखो पैसा कहाँ जा रहा है visually!

🔀 Conditional Formatting
Column D select करो → Home → Conditional Formatting → हरा अगर positive (budget में) → लाल अगर negative (budget से बाहर)!

🔢 Monthly Budget के लिए ज़रूरी Excel Formulas

Formula क्या करता है उदाहरण
=SUM(B4:B6) Cells की range जोड़ता है कुल आमदनी
=B7-C20 दो cells घटाता है बचा हुआ पैसा
=B10-C10 Budget vs Actual अंतर ज़्यादा या कम
=C19/B7*100 प्रतिशत निकालता है बचत का प्रतिशत
=AVERAGE(B4:B6) औसत निकालता है औसत मासिक खर्चा
=MAX(C10:C19) सबसे बड़ी value ढूंढता है सबसे बड़ा खर्चा
